# Other files

Files used while developing the article, kept for the record. They are not needed to reproduce the article, are not maintained, and the scripts may no longer run from this folder.

| File | What it was used for |
|---|---|
| `validation_README.md` | First overview of the validation analyses (October 2026), replaced by the Supporting Information. |
| `false_positive_rate.md` | Working notes on the false-positive rate of the drift-aware threshold, replaced by Supporting Information S2. |
| `monte_carlo_precision.md` | Working notes on the precision of power estimates, replaced by Supporting Information S5. |
| `rescaling.md` | Working notes on the rescaling of long series, replaced by Supporting Information S6. |
| `slim.md` | Working notes on the comparison with SLiM, replaced by Supporting Information S4. |
| `theory.md` | Working notes on the agreement with theory, replaced by Supporting Information S3. |
| `worked_examples_README.md` | First overview of the case studies, replaced by the article and Supporting Information S7. |
| `mc_figure.py`, `monte_carlo_precision.svg` | Early figure of the precision of power estimates, replaced by Figure S3. |
| `make_figure.py`, `rescale_validation.svg` | Early figure of the rescaling comparison, replaced by Figure S4. |
| `slim_figure.py`, `slim_check.svg` | Early figure of the comparison with SLiM, replaced by Figure S2. |
| `small_alpha_thresholds.js`, `small_alpha.tsv` | Exploratory comparison of ways to set the threshold for very small significance levels; not used in the article. |
| `ties_changes.tsv`, `ties_summary.tsv` | Results before and after the change in how ties at the threshold are counted (November 2026). |
